# Poker REST API

REST API for poker that allows you to play a simplified version of Texas Hold'em.

Here is the url of the project : http://pgsandbox.site:9000/pokerapi [NOT ONLINE FOR THE MOMENT]

## Stack

- Java 21
- Spring Boot
- Spring Data JPA
- H2 Database
- Openapi

## Swagger

Here you can find the Swagger UI interface. This interface allows you to view and test the different API endpoints.

http://pgsandbox.site:9000/pokerapi/docs [NOT ONLINE FOR THE MOMENT]
